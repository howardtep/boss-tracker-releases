# Boss Tracker

A Windows desktop app for tracking MapleStory (GMS Heroic) boss clears and weekly crystal income across your main and boss mules.

## Download

Get the latest installer from the [Releases page](../../releases/latest): download `Boss-Tracker-Setup-<version>.exe` and run it.

The app isn't code-signed, so Windows SmartScreen may show "Windows protected your PC" the first time. Click **More info → Run anyway**.

## Updates

The app checks for new versions on its own. When one is ready it shows a banner; click **Restart to update**.

## Features

- Characters with class, level, world and sprite looked up from the official MapleStory rankings
- Weekly, daily and monthly boss checklists that reset with GMS (UTC)
- Party splits, the 14-crystal weekly cap, and earned / max mesos per character
- Weekly income history
- Optional weekly summaries posted to your own Discord channel through a webhook

Your data stays on your PC (`%APPDATA%\Boss Tracker`).

This repository only hosts installers; the source code is private.
